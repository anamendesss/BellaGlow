# 🌸 Bella Glow — Blog de Beleza

O **Bella Glow** é um blog de beleza desenvolvido com HTML, CSS e JavaScript, criado para compartilhar dicas e conteúdos sobre skincare, maquiagem, cuidados com os cabelos e autocuidado.

O projeto tem como objetivo oferecer uma experiência agradável e intuitiva, com uma interface moderna, delicada e responsiva.

## Sobre o projeto

O Bella Glow foi desenvolvido para colocar em prática conhecimentos de desenvolvimento web, utilizando tecnologias fundamentais do front-end.

A identidade visual utiliza tons de rosa, nude e branco, trazendo uma aparência leve e elegante, relacionada ao universo da beleza.

## Funcionalidades

- Página inicial com apresentação do blog.
- Artigos organizados por categorias.
- Filtro de conteúdos por categoria.
- Campo de pesquisa de artigos.
- Opção de favoritar publicações.
- Armazenamento local dos favoritos.
- Seção de newsletter demonstrativa.
- Layout responsivo para computadores e celulares.

## Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores e responsividade.
- **JavaScript:** interatividade, pesquisa, filtros e favoritos.
- **LocalStorage:** armazenamento dos artigos favoritos no navegador.

## Como executar

1. Faça o download do projeto.
2. Extraia os arquivos para uma pasta.
3. Abra a pasta no Visual Studio Code.
4. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

Não é necessário instalar bibliotecas ou configurar um servidor para visualizar o site.
